# Suspected piracy / takedown procedure

1. **Preserve evidence** — URL, capture date (UTC), hashes, screenshots, export IDs.
2. **Ledger lookup** — match export IDs / file hashes via `DeliveryLedger` (candidates only).
3. **Do not auto-accuse** — a match may mean the buyer’s copy was stolen.
4. **Classify** — unauthorized mirror, reseller listing, partial dump, cracked installer.
5. **Action** — platform report / DMCA-style notice where applicable; revoke only with
   clear entitlement abuse; offer device replacement if the buyer was compromised.
6. **Log** — append to the monitor findings log under the studio data directory.
