# Installation and licence recovery (customer)

## Install Academic Studio

1. Download the Studio build for your OS from your purchase email.
2. Open the app (no terminal commands required for the customer build).
3. Choose **Licence → Activate** and enter the licence id from the delivery email.
4. Point Studio at your purchased package folder (the folder that contains `ResearchCatalog.asdb` / delivery files), or let it auto-locate a previously configured package.
5. Open **Faculty library** / **Purchased catalog**. Browse works offline with no AI account.

## Install the standalone dataset

1. Download the dataset ZIP from your purchase email.
2. Extract it. Open `START_HERE.txt`, then `GlobalResearch.xlsx`.
3. Use Excel or LibreOffice. The **Faculty Directory** sheet is a filterable table.

## If the catalog will not open

| Symptom | What to do |
| --- | --- |
| Issuer mismatch (`AS-LIC-ISSUER-MISMATCH`) | Select the original purchased package again. Contact support with your payment reference — do not bypass verification. |
| Wrong device (`AS-LIC-DEVICE`) | Use offline activation / device transfer from Activate help. |
| Expired entitlement (`AS-LIC-EXPIRED`) | Contact support for renewal or re-delivery verification. |
| Signature / corrupt (`AS-LIC-SIGNATURE`) | Re-download the package; do not edit licence files. |

Your research workspace and saved applications are not modified by a failed catalog open.

## Backup and restore

Use **Settings → Backup**. Create a backup before moving computers. Restore previews contents and requires confirmation. Licence keys are not transferred by restoring a workspace backup — activate the licence on the new device separately.

## Privacy

Delete workspace data from **Settings → Privacy**, not from the everyday Applications board.
