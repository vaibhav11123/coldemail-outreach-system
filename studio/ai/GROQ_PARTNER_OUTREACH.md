# Groq partner outreach — delegated authorization request

Until Groq publishes third-party OAuth / device authorization for inference,
Academic Outreach Studio uses **BYOG (Bring Your Own Groq)**: a guided one-time
API-key connection. Do not label the current flow as OAuth.

Suggested outreach email:

---

Hi Groq team,

We're building Academic Outreach Studio, a desktop application that helps
university students discover research opportunities and prepare evidence-backed
academic applications.

We would like students to connect their own GroqCloud accounts and consume their
individual inference allowances directly, without manually creating or copying
API keys.

Does Groq currently offer, or plan to offer, any of the following?

- Third-party OAuth authorization for inference.
- Programmatic, user-authorized API key provisioning.
- Device authorization for desktop applications.
- A partner integration supporting delegated inference access.

Our application would not pool customer quotas or use shared credentials. Each
student would retain control over their own account and usage.

We would be interested in integrating an officially supported authorization flow.

Thanks,
Vaibhav Singh
